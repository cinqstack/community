# cinqstack community

cinqstack keeps NetBox true to the plant: device sync, Purdue topology,
segmentation and firewall data flows, fully offline.

This is the place to ask questions, share what worked on your plant and
tell us what is missing. There is no code here.

- **Ask or discuss:** [Discussions](https://github.com/cinqstack/community/discussions)
- **Docs:** https://cinqstack.com/docs/
- **Download:** https://cinqstack.com/download.html

## Before you post

Please leave out anything that identifies your site: IP addresses, host
names, device names and configs. Describe the setup instead
("a Purdue level 2 switch behind a firewall").

## Pro and Enterprise

Write to support@cinqstack.com with your licence ID. Response times are
in the [support policy](https://cinqstack.com/support-policy.html).

## Security

Please don't report vulnerabilities here. Email security@cinqstack.com.
